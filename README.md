# ¿Por qué no voto?

La información utilizada en este proyecto se obtuvo de fuentes oficiales, principalmente del Instituto Nacional Electoral (INE), mediante los Conteos Censales de Participación Ciudadana de 2009 a 2024. Además, se complementó con datos del INEGI, relacionados con la población, escolaridad, empleo y acceso a tecnologías; del CONAPO, mediante el Índice de Marginación; y de indicadores de desarrollo humano y condiciones socioeconómicas. Estas fuentes permitieron analizar las diferencias en la participación electoral según la edad, el sexo y las características de cada territorio, con el propósito de identificar perfiles ciudadanos y proponer estrategias para fomentar el voto.

### Perfiles de participación electoral según edad, sexo y contexto territorial

Este proyecto forma parte del **Reto 1 del INE: Perfiles ciudadanos de participación**. Buscamos conocer cómo cambia la participación electoral en México y qué se puede hacer para motivar a más personas a votar.

A partir de los datos de participación del **INE (2009–2024)** y de información de contexto de otras fuentes, se identificaron cuatro perfiles:

- **Adultos mayores comprometidos:** suelen participar con frecuencia.
- **Votantes estables del Norte:** mantienen una participación regular.
- **Votantes de elección presidencial:** participan más cuando se elige la presidencia.
- **Hombres jóvenes alejados de las urnas:** presentan los niveles más bajos de participación.

## ¿Qué hace nuestro dashboard?

Permite seleccionar un **estado, municipio, localidad y perfil** para explorar los resultados. Al dar clic en **Aceptar**, aparecen los datos del perfil elegido y las **estrategias que proponemos para fomentar la participación ciudadana**.


## Nota sobre los datos

Esta es una **demostración con datos simulados para los filtros geográficos**. Las fichas de los cuatro perfiles muestran información fija tomada de nuestro documento técnico: sus porcentajes corresponden a los perfiles a nivel nacional, **no al estado, municipio o localidad seleccionados**.
